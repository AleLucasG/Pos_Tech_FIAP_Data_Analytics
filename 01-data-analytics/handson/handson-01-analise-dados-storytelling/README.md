# Analisando dados com Python

## Descrição da Atividade

Neste hands-on, foi realizada uma análise de dados sobre casos de Dengue no Brasil, utilizando dados do DataSUS. 
O objetivo foi explorar, tratar e analisar as informações para identificar padrões, tendências e os estados com maior incidência da doença.

Durante o processo, foram aplicadas técnicas de manipulação de dados, análise estatística e visualização gráfica, utilizando ferramentas como Pandas, NumPy, Matplotlib e Seaborn. 
A análise permitiu compreender a distribuição dos casos ao longo do tempo e destacar a importância de medidas preventivas, como a vacinação, no controle da doença.

## Criando Storytelling com Dados

Neste hands-on, foi construída uma narrativa a partir da análise de dados de casos de dengue no Brasil, utilizando informações do DataSUS. O objetivo foi transformar dados em insights, identificando os estados e regiões com maior incidência da doença ao longo do tempo.

A análise buscou não apenas apresentar números, mas contextualizar o cenário, destacando padrões, variações e possíveis surtos. 
Com isso, foi possível compreender melhor o impacto da dengue na população e reforçar a importância de ações preventivas, como políticas públicas e vacinação.

O storytelling com dados permitiu conectar os resultados obtidos à realidade, tornando a análise mais clara, estratégica e orientada à tomada de decisão.
