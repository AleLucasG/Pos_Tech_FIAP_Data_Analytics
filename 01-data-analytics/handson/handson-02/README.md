# Hands-on 02

Atividade prática desenvolvida durante a Fase 01 - Data Analytics.

## Objetivo

Aplicar conceitos de análise exploratória de dados utilizando dados reais.

## Fonte dos dados

Os dados utilizados nesta atividade foram obtidos no portal **DATASUS - Informações de Saúde (TABNET)**.

https://datasus.saude.gov.br/informacoes-de-saude-tabnet/
