# Pos Tech FIAP - Data Analytics

Repositório com atividades, exercícios práticos (hands-on) e projetos desenvolvidos durante a **Pós-Tech FIAP em Data Analytics**.

## Sobre a Pós-Tech

A Pós-Tech em Data Analytics é uma pós-graduação com foco prático em análise de dados, visualização e tomada de decisão baseada em dados. O programa possui aproximadamente **360 horas e duração média de 10 meses**, com conteúdos voltados para aplicação real no mercado.

Durante o curso são utilizados conceitos e ferramentas para manipulação de dados, criação de indicadores, análise estatística, machine learning e visualização de dados.

## Estrutura do curso

O curso é dividido em **5 fases**, onde cada fase aborda um conjunto de conceitos e termina com um **Tech Challenge**, um projeto aplicado que consolida o aprendizado.

As fases incluem temas como:

* Data Analytics e análise exploratória de dados
* Machine Learning aplicado a negócios
* Big Data e engenharia de dados
* Visualização de dados e construção de dashboards
* IA generativa aplicada à análise de dados

Algumas das tecnologias utilizadas ao longo da pós-graduação incluem:

Organizar e documentar a evolução dos estudos durante a pós-graduação, além de reunir projetos práticos que demonstram a aplicação dos conceitos de **Data Analytics**.
